# ❤️ Heart Disease Prediction Web Application

## 📌 About
A machine learning-based web application that predicts the possibility of heart disease using patient health parameters.

## ✨ Features
- User Registration and Login
- Heart Disease Prediction
- Random Forest Classification
- Prediction Probability
- Prediction History Management
- SQLite Database Integration
- User-Friendly Web Interface

## 🛠️ Technologies Used
- Python
- Flask
- HTML, CSS, JavaScript
- Machine Learning
- Scikit-learn
- Pandas
- SQLite
- Joblib

## 🧠 Algorithm
Random Forest Classifier.

## 📊 Input Parameters
Age, Sex, Chest Pain Type, Blood Pressure, Cholesterol, Blood Sugar, ECG, Maximum Heart Rate, Exercise Angina, Oldpeak, Slope, CA, and Thal.

## ⚙️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/heart-disease-prediction-system.git

cd heart-disease-prediction-system

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python app.py
```

Open in browser:

`http://127.0.0.1:5000`
